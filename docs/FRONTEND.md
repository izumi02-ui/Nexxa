# NEXXA Frontend

**Creator:** ROHIT CHAKRABORTY (IZ / IZUMI)

## Design Direction

NEXXA should have:

- a dark interface
- a premium appearance
- futuristic but restrained visuals
- strong visual hierarchy
- responsive layouts
- Android-first usability
- fast interactions

NEXXA should not resemble a generic administration dashboard.

## Main Navigation

Planned sections:

- Home
- Search
- Library
- Playlists
- Favorites
- Downloads
- Import
- Radio
- Settings

## Search

Search should present normalized results from supported providers.

Possible categories:

- Songs
- Albums
- Artists
- Playlists
- Videos
- Providers

## Player

The persistent player should provide:

- artwork
- title
- artist
- progress
- play/pause
- previous
- next
- queue
- lyrics

## Import UI

The user should see clear import states:

```text
CONNECTING
AUTHENTICATING
DISCOVERING
MATCHING
PREVIEW
IMPORTING
COMPLETED
FAILED
```

## Required UI States

Every major screen needs:

- loading state
- empty state
- error state
- success state

## Mobile

Do not simply shrink the desktop layout.

Use:

- touch-friendly controls
- bottom navigation where appropriate
- safe areas
- responsive player
- accessible buttons
- readable typography
