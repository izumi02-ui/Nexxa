# NEXXA Frontend

## Design Direction

NEXXA should have:

- dark interface
- premium appearance
- futuristic but restrained visuals
- strong hierarchy
- responsive layouts
- Android-first usability
- fast interactions

NEXXA should not look like a generic admin dashboard.

---

# Main Navigation

Planned:

- Home
- Search
- Library
- Playlists
- Favorites
- Downloads
- Import
- Radio
- Settings

---

# Search

Search should support normalized results from supported providers.

Possible categories:

- Songs
- Albums
- Artists
- Playlists
- Videos
- Providers

---

# Player

Persistent player:

- artwork
- title
- artist
- progress
- play/pause
- previous
- next
- queue
- lyrics

---

# Import UI

The user should see clear states:

```text
CONNECTING
AUTHENTICATING
DISCOVERING
MATCHING
PREVIEW
IMPORTING
COMPLETED
FAILED
```

---

# Required UI States

Every major screen needs:

- loading state
- empty state
- error state
- success state

---

# Mobile

Do not simply shrink the desktop layout.

Use:

- touch-friendly controls
- bottom navigation where appropriate
- safe areas
- responsive player
- accessible buttons
- readable typography
